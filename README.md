# Mobile Sales Dashboard - Power BI Project

## Overview
An interactive Power BI dashboard for analyzing mobile phone sales across brands, cities, payment methods, and time periods. The dashboard provides insights into sales performance, customer behavior, and product trends.

## Key Features
- Sales trend analysis
- Brand and model performance comparison
- Payment method analysis
- Customer rating insights
- Geographic sales visualization
- Interactive slicers for detailed analysis

## Tools Used
- Power BI Desktop
- Power Query
- DAX

## Skills Demonstrated
Data Cleaning, Data Modeling, DAX, KPI Creation, Dashboard Design, and Business Intelligence Reporting.

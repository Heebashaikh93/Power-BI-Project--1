# Mobile Sales Dashboard - Power BI Project

## Overview

This Power BI dashboard provides an interactive analysis of mobile phone sales performance across different cities, brands, payment methods, and time periods. The report helps users monitor key business metrics, identify sales trends, and gain insights into customer purchasing behavior.

---

## Project Objectives

* Analyze overall sales performance.
* Track sales trends over time.
* Compare performance across mobile brands and models.
* Understand customer payment preferences.
* Evaluate customer ratings and transaction activity.
* Provide interactive filtering for detailed business analysis.

---

## Key Performance Indicators (KPIs)

The dashboard includes the following KPIs:

* **Total Sales**
* **Total Quantity Sold**
* **Total Transactions**
* **Average Sales Value**

---

## Dashboard Features

### 1. Interactive Filters (Slicers)

Users can filter the dashboard by:

* Month
* Mobile Model
* Payment Method
* Day Name
* Brand

### 2. Geographic Analysis

* Map visualization showing sales distribution across cities.
* Bubble size represents total sales.

### 3. Sales Trend Analysis

* Line chart displaying units sold over time.
* Helps identify seasonal and monthly sales patterns.

### 4. Product Performance

* Clustered column chart comparing total sales by mobile model.
* Enables identification of top-performing products.

### 5. Payment Method Analysis

* Pie chart showing transaction distribution across payment methods.
* Helps understand customer payment preferences.

### 6. Customer Rating Analysis

* Funnel chart analyzing customer ratings.
* Provides insights into customer satisfaction levels.

### 7. Weekly Sales Analysis

* Area chart displaying sales performance by day of the week.

### 8. Detailed Sales Table

Includes:

* Brand
* Total Sales
* Total Quantity Sold
* Total Transactions
